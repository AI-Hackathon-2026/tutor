# AI-Tutor 🎓

**AI-Tutor** — это умная платформа для создания персонализированных образовательных траекторий с использованием искусственного интеллекта.

## Как запустить

Склонируйте репозиторий, добавьте graph_agent.env, test_agent.env, sandbox_environment.env и общий .env с git токеном и паролем postgres.

Запустите ```docker compose up```

## Как это работает

### 1. Начало работы
Перейдите на главную страницу сайта. Вы можете:
- **Создать аккаунт**: Укажите email, придумайте уникальное имя пользователя и пароль (подтвердите его).
- **Войти в систему**: Используйте свою почту и пароль для доступа к личному кабинету.
- Просмотреть отзывы других пользователей, чтобы узнать больше о проекте.

### 2. Управление курсами
После авторизации вам открывается доступ ко всем курсам.
- **Создание курса**: Опишите свои пожелания — AI сгенерирует для вас персональный учебный план.
- **Редактирование**: Вносите изменения в существующие курсы в любой момент.

### 3. Процесс обучения
После создания курса формируется детальный **roadmap** (дорожная карта) изучения темы.
1.  Начинайте изучение с первой темы.
2.  Отслеживайте свой прогресс по мере прохождения материала.

### 4. Проверка знаний
Чтобы подтвердить освоение темы и отметить прогресс, вам нужно пройти **собеседование с AI-ботом**.
- Бот задает вопросы по пройденному материалу.
- По итогам вы получаете подробный результат и рекомендации по улучшению.
- Не бойтесь ошибаться: в случае неудачи можно попробовать снова, чтобы закрепить результат.
