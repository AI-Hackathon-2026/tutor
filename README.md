# AI-Tutor 🎓

**AI-Tutor** — это умная платформа для создания персонализированных образовательных траекторий с использованием искусственного интеллекта.

## Как запустить

### 1. Подготовка репозитория
Склонируйте проект, перейдите в рабочую директорию и переключитесь на ветку разработки:

```bash
git clone https://github.com/AI-Hackathon-2026/tutor.git
cd tutor
git checkout develop
```

### 2. Подготовка GitHub Token
Для доступа к приватным зависимостям вам потребуется персональный токен GitHub (**PAT**).
1. Перейдите в [GitHub Settings > Tokens](https://github.com/settings/tokens).
2. Создайте новый токен (classic) с правами на `repo`.
3. Сохраните его — он понадобится в следующем шаге.

### 3. Настройка окружения (`.env` файлы)
В корневой папке проекта необходимо создать несколько файлов конфигурации. Заполните их соответствующими ключами:

| Файл | Ключи и параметры |
| :--- | :--- |
| **`.env`** | `token=<ваш_github_token>` <br> `POSTGRES_PASSWORD=<пароль>` |
| **`graph_agent.env`** | `POSTGRES_PASSWORD=<пароль>` |
| **`sandbox_environment.env`** | `POSTGRES_PASSWORD=<пароль>` |
| **`test_agent.env`** | `LANGFUSE__SECRET_KEY=<key>` <br> `LANGFUSE__PUBLIC_KEY=<key>` <br> `LANGFUSE__OTEL_TIMEOUT=<timeout>` |
| **`admin_panel.env`** | *(создайте файл пустым)* |

> [!TIP]
> Убедитесь, что пароль для PostgreSQL совпадает во всех указанных файлах для корректной связки контейнеров.

### 4. Запуск приложения
Запустите сборку и старт всех сервисов через Docker Compose:

```bash
docker compose up --build
```

### 5. Открыть тьютор
Введите в поисковую строку:
```bash
localhost:5173
```
## Как это работает

### 1. Начало работы
Перейдите на главную страницу сайта. Вы можете:
- **Создать аккаунт**: Укажите email, придумайте уникальное имя пользователя и пароль (подтвердите его).
- **Войти в систему**: Используйте свою почту и пароль для доступа к личному кабинету.
- Просмотреть отзывы других пользователей, чтобы узнать больше о проекте.

### 2. Управление курсами
После авторизации вам открывается доступ ко всем курсам.
- **Создание курса**: Опишите свои пожелания — AI сгенерирует для вас персональный учебный план.
- **Редактирование**: Вносите изменения в существующие курсы в любой момент.

### 3. Процесс обучения
После создания курса формируется детальный **roadmap** (дорожная карта) изучения темы.
1.  Начинайте изучение с первой темы.
2.  Отслеживайте свой прогресс по мере прохождения материала.

### 4. Проверка знаний
Чтобы подтвердить освоение темы и отметить прогресс, вам нужно пройти **собеседование с AI-ботом**.
- Бот задает вопросы по пройденному материалу.
- По итогам вы получаете подробный результат и рекомендации по улучшению.
- Не бойтесь ошибаться: в случае неудачи можно попробовать снова, чтобы закрепить результат.
